# 셈판 🧮

사칙연산으로 몹을 쓰러뜨리는 덱빌딩 로그라이크.
숫자 카드와 기호 카드로 수식을 만들어 피해를 주고, 갈림길을 골라 오르며 덱을 키워 나가요.

## 플레이 방법

- 손패에서 숫자와 기호를 번갈아 골라 최대 5장(숫자 3, 기호 2)짜리 수식을 만들어요.
- 수식은 왼쪽부터 순서대로 계산하고, 결과만큼 몹에게 피해를 줘요.
- 계산 기회 안에 몹 체력을 0으로 만들면 승리, 못 하면 게임 오버예요.
- 승리하면 골드를 받고 특전을 골라 카드를 강화해요.

## 주요 시스템

**갈림길 지도**
막마다 10층짜리 지도가 무작위로 생성돼요. 층마다 1~3갈래 길이 생기고, 몹 · 정예 · 상점 중 갈 곳을 골라요. 10층 보스를 잡으면 다음 막으로 넘어가요.

**경제**
골드 = 처치 보상 + 초과 피해 골드 + 남은 계산 × 단가 + 남은 버리기 × 단가

- 초과 피해 골드는 로그 곡선으로 빠르게 꺾이고 상한이 있어요.
- 모든 보상과 상점 가격은 적 체력과 함께 지수적으로 커져요.
- 상점에서 산 카드는 같은 종류의 덱 카드와 교환돼요. 덱 크기는 항상 그대로예요.

**카드 강화**
| 종류 | 효과 |
|---|---|
| 황금 | 최종 결과 ×2 |
| 불꽃 | 최종 결과에 보너스 추가 |
| 행운 | 25% 확률로 최종 결과 ×5 |
| 증폭 (+) | 오른쪽 수를 세 배로 더함 |
| 적립 (+) | 보너스를 더하고, 쓸 때마다 보너스 증가 |
| 역전 (−) | 절댓값으로 바꾸고 ×4 |
| 정확 (÷) | 나누어떨어지면 곱하고 ×2 |

× 카드는 강력한 대신 강화할 수 없어요.

**숫자 변신 (막별 해금)**
| 해금 | 변신 | 입력 상한 |
|---|---|---|
| 2막 | 제곱 n² | 20 |
| 3막 | 2의 거듭제곱 2ⁿ | 15 |
| 4막 | 자연지수 eⁿ | 12 |
| 5막 | 팩토리얼 n! | 10 |

## 실행

빌드 과정이 없는 단일 HTML 파일이에요.

```bash
git clone https://github.com/<사용자명>/sempan.git
cd sempan
open index.html   # 또는 브라우저로 직접 열기
```

## 밸런스 조정

`index.html` 스크립트 맨 위의 `CFG` 객체와 `TR` 배열에서 대부분의 수치를 바꿀 수 있어요.

| 항목 | 설명 |
|---|---|
| `baseHP`, `actGrowth` | 1층 체력과 막별 층당 체력 배율 |
| `econPow` | 보상·가격이 체력을 따라가는 정도 |
| `goldA`, `goldK`, `goldCap` | 초과 피해 골드 곡선 |
| `playGold`, `discGold` | 남은 계산·버리기 단가 |
| `fireBase`, `firePow` | 불꽃 보너스 크기 |
| `TR[].cap` | 변신별 입력 상한 |

## 기술 스택

- Vanilla JavaScript, HTML, CSS (외부 라이브러리 없음)
- 최고 기록은 브라우저 localStorage에 저장
- 라이트/다크 모드, 모바일 터치 지원
